# Memory Game in C

## Overview
Memory Game is a console-based game developed in C using Turbo C. The objective is to match pairs of hidden cards by remembering their positions. The project demonstrates concepts such as arrays, loops, functions, conditional statements, and randomization.

## Features
- Console-based user interface
- Randomized card arrangement
- Memory matching gameplay
- Score tracking
- Win/Lose condition

## Technologies Used
- C Programming
- Turbo C

## How to Run
1. Open the project in Turbo C.
2. Compile the source code.
3. Run the program.
4. Follow the on-screen instructions to play the game.
